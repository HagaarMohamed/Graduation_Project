

A Multimodal AI graduation project that recognizes ancient Egyptian artifacts and retrieves verified historical context using fine-tuned CLIP and RAG (Retrieval-Augmented Generation).

---

## 🔄 System Inputs & Outputs

### 📥 1. Inputs
* **User Image:** Uploaded photo or live camera capture (`.jpg`, `.jpeg`, `.png`, `.webp`) of an Egyptian artifact.

### 📤 2. Outputs
* **Matched Reference Image:** The official, verified high-quality photo of the recognized artifact from the database.
* **Artifact Identity:** The name of the detected monument along with the confidence/similarity percentage (e.g., *Statue of Ramesses II (94.25%)*).
* **Historical Description:** A comprehensive, long-form historical context retrieved directly from verified database records.

---

## ⚙️ How to Run
1. Mount Google Drive and run the initialization cells to load the model.
2. Load the pre-computed embeddings index (`.pkl` file) into RAM.
3. Run the **Gradio Interface** cell and use the generated link to test the application.
