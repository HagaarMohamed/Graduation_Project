# Pipeline 1: PDF Parser, Summarization, and Question Answering System

This folder contains my work (**Hagar**) in **Pipeline 1**.

## Notebook 1

### `pdf_parser_summarization_with_QA_Qwen.vl.ipynb`

This notebook implements an end-to-end PDF processing and Question Answering system capable of handling both **Arabic** and **English** documents.

### Input

* PDF documents (Arabic or English)

### Output

* Document Summary
* Suggested Questions
* Question & Answering Interface

---

## System Flow

```text
PDF → Parse (PyMuPDF) → Chunk Text → ChromaDB (RAG)
        ↓
User asks question → RAG retrieves relevant chunks
        ↓
Groq (LLaMA) generates grounded answer
        ↓
Groq suggests relevant questions
        ↓
ANKH assistant persona enables users to ask any question related to the uploaded document
```

---

## Components

### PDF Parsing

* Uses **PyMuPDF** to extract text from uploaded PDF files.

### Text Processing

* Extracted text is divided into chunks for efficient retrieval and context management.

### Retrieval-Augmented Generation (RAG)

* Chunks are stored in **ChromaDB**.
* Relevant document sections are retrieved based on user queries.

### Question Answering

* **Groq (LLaMA)** generates grounded answers using the retrieved document context.

### Question Suggestion

* Groq automatically generates suggested questions related to the uploaded document.

### ANKH Assistant

* ANKH acts as the assistant persona.
* Users can interact with ANKH and ask any question about the uploaded document.

### User Interface

* The complete workflow is deployed through a **Gradio UI**, providing an interactive user experience.

---

## Features

* Supports both **Arabic** and **English** PDF documents.
* Automatic document summarization.
* Retrieval-Augmented Generation (RAG) using ChromaDB.
* Context-aware question answering.
* AI-generated suggested questions.
* Interactive ANKH assistant persona.
* Fully deployed with Gradio UI.
